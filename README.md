# Hasibul Hasan — Academic Website

A minimal, responsive academic website for GitHub Pages. It uses a Computer Modern / Latin Modern-style font.

## Pages

- `index.html` — Home and biography, including the profile photograph
- `research.html` — Research
- `teaching.html` — Teaching
- `cv.html` — Curriculum Vitae

## Add your photograph

1. Open the `assets` folder in your GitHub repository (create it if needed).
2. Upload your portrait photograph and name it exactly `profile.jpg`.
3. The expected path is `assets/profile.jpg`.

The site disables right-click and dragging on the displayed portrait as a basic deterrent. This cannot prevent someone from retrieving a public image through browser developer tools, the page source, or a screenshot. Do not upload a photograph if you need it to be technically inaccessible to visitors.

## Add your CV

Upload your CV PDF into `assets` and name it exactly `Hasibul_Hasan_CV.pdf`. The expected path is `assets/Hasibul_Hasan_CV.pdf`.

## Publish

Upload the contents of this folder to the root of your GitHub Pages repository, replacing the previous files. Commit the changes to the branch configured in Settings → Pages.
