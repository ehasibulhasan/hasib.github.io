# Hasibul Hasan — Academic Website

A minimal, responsive academic website using the Computer Modern / Latin Modern-style font. The homepage contains the biography and portrait side by side; the portrait is on the left and the text is on the right on desktop.

## Add your photograph (required to show your actual photo)

1. Open the `assets` folder in your GitHub repository.
2. Upload your own portrait photograph.
3. Name the file exactly `profile.jpg`.
4. The final path must be `assets/profile.jpg` (not `profile.jpg` in the repository root).

Until you upload your photo, the homepage displays a placeholder. On desktop, the photo is left of the biography; on narrow screens, it moves above the text.

The site disables right-click and dragging on the displayed portrait as a basic deterrent. This cannot prevent someone from retrieving a public image through browser developer tools, the page source, or a screenshot.

## Add your CV

Upload your CV PDF into `assets` and name it exactly `Hasibul_Hasan_CV.pdf`.

## Pages

- `index.html` — Home and biography
- `research.html` — Research
- `teaching.html` — Teaching
- `cv.html` — Curriculum Vitae

Upload the contents of this folder to the root of your GitHub Pages repository, replacing the previous files, then commit the changes. Remove any old `about.html` file from the repository if it remains from an earlier version.

Contact: `hasib.hasan@colorado.edu`


The site name “Hasibul Hasan” in the header links to the homepage. There is no separate Home navigation item; use Research, Teaching, and CV to navigate to the other pages. The homepage portrait is displayed in a compact left column beside the biography. Add your image as `assets/profile.jpg`.
